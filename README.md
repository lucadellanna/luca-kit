# luca-ops-kit

A Claude Code plugin that helps non-technical teams turn business procedures, SOPs, and operating knowledge into reusable AI skills.

## Skills

| Skill | What it does |
|-------|-------------|
| **create-skill** | Guides you through turning a procedure, SOP, or task description into a reusable Claude skill with built-in quality scoring |
