**`targeted-review`** Single-file code review with a file-specific checklist; for developers who want a tighter pass than `triple-review` on a specific file with non-obvious invariants. The main agent derives a checklist tailored to the file (or accepts your own), then spawns a subagent that returns bug-only findings against it. **Example:** "I just wrote a caching layer with TTL-write ordering invariants; review it" -> `/targeted-review src/cache.ts`.
