**`compact-claude-files`** scans the files Claude Code loads automatically (your `CLAUDE.md`, memory files in `.claude/memory/`, and path-rule files in `.claude/rules/`) and tightens them within each file -- removing redundant phrasing, merging duplicate bullets, and compressing verbose sentences. It does not move content between files; for cross-file reorganization (memory ↔ CLAUDE.md, path-rule extraction, project ↔ global rebalancing), use `/luca-kit:restructure-claude-files`. **Example:** "My CLAUDE.md is bloated after months of additions" → `/luca-kit:compact-claude-files`.
