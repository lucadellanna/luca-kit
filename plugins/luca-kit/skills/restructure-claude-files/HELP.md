**`restructure-claude-files`** reorganizes content across the files Claude Code loads automatically (your `CLAUDE.md`, memory files in `.claude/memory/`, and path-rule files in `.claude/rules/`). It moves content out of CLAUDE.md to co-located memory, surfaces memory entries that should be promoted to standing CLAUDE.md rules, identifies content that should become path-scoped rule files, and flags scope mismatches between project and global CLAUDE.md. Memory moves apply automatically; the rest is surfaced as advice. For within-file compaction (redundancy removal, sentence shortening), use `/luca-kit:compact-claude-files`. **Example:** "My CLAUDE.md has rules that should really be path-scoped" → `/luca-kit:restructure-claude-files`.
