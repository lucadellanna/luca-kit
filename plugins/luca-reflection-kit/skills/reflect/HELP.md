**`reflect`** turns the current Claude Code conversation into concrete takeaways: memory entries Claude can use next time, proposed edits to your skills or rules, and a few hints about how to use Claude more effectively in future sessions. Clear low-risk memory entries are saved automatically; everything else is presented for you to approve before any change is made. **Example:** "Reflect on our session. What did we learn?" → `/luca-reflection-kit:reflect`.
